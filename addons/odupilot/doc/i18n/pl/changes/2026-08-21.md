# 2026-08-21

## Portrety AI w bocznym pasku dyskusyjnym

- Każda rozmowa AI pokazuje teraz portret asystenta AI w okrągłej ikonie obok jej nazwy. Istniejące rozmowy AI otrzymują je podczas aktualizacji modułu, a nowe rozmowy otrzymują je, gdy są tworzone.

## Ręczne nazwy rozmów

- Ołówek obok tytułu rozmowy AI otwiera teraz edytor nazw inline. Naciśnij **Wpisz**, aby zachować nową nazwę lub **Ucieczka** anulować. Ręcznie ustawiona nazwa nie jest nadpisana po zakończeniu pierwszej odpowiedzi AI.

## File- tylko przestrzeń robocza dla pytań rozmowy

- Sesja ukrytych usług za **Zapytaj AI** teraz zawsze używa tylko pliku workspace. Nawet z profilem dewelopera nie rezerwuje już gałęzi Git lub drzewa roboczego, otrzymuje deweloper- narzędzia środowiska lub referencje, lub zawiera instrukcje przepływu pracy deweloperów.

## Sesja Dostęp do odo

- OduPilot teraz sprawdza **MCP Aktywne** i przypisany profil MCP bezpośrednio, gdy każda rozmowa zaczyna. Nie potrzebuje on już stałego klucza API wybranego jako domyślny czat AI.
- Każda kwalifikująca się rozmowa nadal otrzymuje swój tymczasowy klucz MCP, który zostaje cofnięty po zamknięciu lub usunięciu rozmowy.
