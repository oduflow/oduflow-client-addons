# 2026-08-16

## Rozmowy z AI w dyskusjach

- Dodano prywatne rozmowy AI poparte jedną niezależną sesją OpenCode.
- Dodano automatyczne routing w czatach jednoosobowych i wyraźne routing **@ AI** w czatach wspólnych.
- Dodano zaproszenia kontrolowane przez właściciela ze wspólnymi uprawnieniami właściciela i widoczną tożsamością autora.
- Dodano załączniki plików, `/abort`, dostarczanie odpowiedzi async i harmonogram audytu.
- Przesunął cały stos wdrożeniowy OduPilot pod katalogiem `deploy/` modułu, więc jego pliki runtime i publikowanie skryptu pozostają razem.
- Pozwoliła zaproszonym uczestnikom na samodzielne odejście i sprawiła, że standardowe rozmowy właściciela pozostawiają działanie blisko i oczyszczają sesję AI.
- Dodano lokalne i zdalne definicje serwerów MCP do wielokrotnego użytku z ścisłą walidacją konfiguracji OpenCode i wyborem serwera profilowego.
- Zmieniono nazwę na **URL bazy AI**.
- Włącza profile deweloperskie do korzystania z niezależnych repozytoriów, gałęzi bazowych i legitymacji GitHub i tworzy wyizolowaną gałąź dwusłowną Git dla każdego czatu.
- Stałe prywatne Uwierzytelnianie repozytorium GitHub poprzez przekazywanie uwierzytelniania profilu przez tymczasowe środowisko `GIT_ASKPASS` bez ujawniania PAT w URL repozytorium lub argumentów procesu.
- Usunięto współdzieloną zależność systemu plików pomiędzy Odoo i OpenCode. Pasek boczny przygotowuje teraz drzewa robocze Git, pisze konfigurację OpenCode i załączniki oraz usuwa miejsca pracy w hoście OpenCode.
- Wykonano nowo utworzoną konwersację AI, która pojawiła się natychmiast na otwartym pasku dialogowym, bez przeładowania strony przeglądarki.
