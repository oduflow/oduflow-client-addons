# Start Chat niezawodnie otwiera nową rozmowę

Rozpoczęcie czatu z listy agentów (przycisk Start Chat) nie pokazuje już
błędu „Missing Record”: Dyskusje otwierają teraz zawsze kanał nowo
utworzonej rozmowy, zamiast używać identyfikatora rekordu z wiersza
listy.
