# Start Chat надёжно открывает новый разговор

Запуск чата из списка агентов (кнопка Start Chat) больше не показывает
ошибку «Missing Record»: Обсуждения теперь всегда открывают канал
только что созданного разговора, а не подставляют идентификатор записи
из строки списка.
