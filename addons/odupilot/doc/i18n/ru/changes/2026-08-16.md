# 2026-08-16

## AI-беседы в Обсуждениях

- Добавлены приватные AI-беседы на основе независимых сессий OpenCode.
- Добавлена автоматическая маршрутизация в чатах с одним пользователем и
  явная маршрутизация через **@AI** в общих беседах.
- Добавлены управляемые владельцем приглашения с общими правами владельца и
  передачей личности фактического автора.
- Добавлены вложения файлов, `/abort`, асинхронная доставка ответов и
  аудит-таймлайн.
- Полный стек развёртывания OduPilot перенесён в каталог `deploy/` модуля, чтобы
  runtime-файлы и скрипт публикации хранились вместе.
- Приглашённым участникам разрешено выходить независимо, а стандартное действие
  выхода владельца в Обсуждениях теперь закрывает и очищает AI-сессию.
- Добавлены повторно используемые определения локальных и удалённых MCP-серверов
  со строгой валидацией конфигурации OpenCode и выбором серверов в профиле.
- Настройка OpenAI-совместимого адреса переименована в **Базовый URL AI**.
- Профили разработчика теперь используют независимые репозитории, базовые ветки
  и учётные данные GitHub и создают для каждого чата изолированную Git
  worktree-ветку с именем из двух слов.
- Исправлена авторизация в приватных GitHub-репозиториях: учётные данные профиля
  передаются через временное окружение `GIT_ASKPASS`, а PAT не попадает в URL
  репозитория или аргументы процесса.
- Убрана зависимость от общей файловой системы между Odoo и OpenCode.
  Теперь sidecar готовит Git worktree, записывает конфигурацию OpenCode и
  вложения, а также удаляет рабочие каталоги на стороне OpenCode.
- Новая AI-беседа теперь сразу появляется в открытой боковой панели
  Обсуждений без перезагрузки страницы браузера.
