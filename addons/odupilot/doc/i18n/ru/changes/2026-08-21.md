# 2026-08-21

## Портрет AI в боковой панели Обсуждений

- Теперь у каждой беседы с AI в круглой иконке рядом с названием показан
  портрет AI-ассистента. Существующие беседы получают его при обновлении
  модуля, а новые — при создании.

## Ручные названия бесед

- Карандаш рядом с заголовком беседы с AI теперь открывает встроенный редактор
  имени. Нажмите **Enter**, чтобы сохранить новое имя, или **Escape**, чтобы
  отменить. Заданное вручную имя не перезаписывается после завершения первого
  ответа AI.

## Только файловый workspace для вопросов из чаттера

- Скрытая служебная сессия кнопки **Спросить AI** теперь всегда использует
  файловый workspace. Даже с профилем разработчика она больше не резервирует
  Git-ветку или worktree, не получает инструменты или реквизиты окружения
  разработчика и не содержит инструкции процесса разработки.

## Сессионный доступ к Odoo

- Теперь при запуске каждой беседы OduPilot напрямую проверяет **MCP Active** и
  назначенный MCP-профиль. Постоянный API-ключ, выбранный ключом OduPilot по
  умолчанию, больше не нужен.
- Каждая подходящая беседа по-прежнему получает собственный временный MCP-ключ,
  который отзывается при закрытии или удалении беседы.
