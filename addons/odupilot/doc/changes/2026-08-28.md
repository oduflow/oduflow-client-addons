# 2026-08-28

- **Ask AI** notes now identify themselves as AI questions immediately, show
  an active processing status and finish as **Answered** or **Failed**. An open
  chatter picks the result up in place, without reloading the record, so work
  in progress next to it is no longer lost — and a colleague working on another
  record of the same model is no longer interrupted either. Bridge command
  failures are written into every affected question instead of leaving it
  unanswered; the upgrade also closes questions already stranded by such
  failures, while leaving alone the queue of a session that recovered.
