# 2026-08-16

## AI conversations in Discuss

- Added private AI conversations backed by one independent OpenCode session.
- Added automatic routing in one-person chats and explicit **@AI** routing in
  shared chats.
- Added owner-controlled invitations with shared owner permissions and visible
  author identity.
- Added file attachments, `/abort`, async response delivery and an audit
  timeline.
- Moved the complete OduPilot deployment stack under the module's `deploy/`
  directory so its runtime files and publishing script stay together.
- Allowed invited participants to leave independently and made the owner's
  standard Discuss leave action close and clean up the AI session.
- Added reusable local and remote MCP server definitions with strict OpenCode
  configuration validation and profile-level server selection.
- Renamed the OpenAI-compatible endpoint setting to **AI base URL**.
- Enabled developer profiles to use independent repositories, base branches
  and GitHub credentials and create an isolated two-word Git worktree branch
  for every chat.
- Fixed private GitHub repository authentication by passing profile credentials
  through a temporary `GIT_ASKPASS` environment without exposing the PAT in the
  repository URL or process arguments.
- Removed the shared filesystem dependency between Odoo and OpenCode. The
  sidecar now prepares Git worktrees, writes OpenCode configuration and
  attachments, and removes workspaces on the OpenCode host.
- Made a newly created AI conversation appear in the open Discuss sidebar
  immediately, without reloading the browser page.
