# 2026-08-21

## AI portraits in the Discuss sidebar

- Every AI conversation now shows the AI assistant portrait in the round icon
  beside its name. Existing AI conversations receive it during the module
  upgrade, and new conversations receive it when they are created.

## Manual conversation names

- A pencil beside the AI conversation title now opens the inline name editor.
  Press **Enter** to keep the new name or **Escape** to cancel. A manually set
  name is not overwritten when the first AI answer finishes.

## File-only workspace for chatter questions

- The hidden service session behind **Ask AI** now always uses a file-only
  workspace. Even with a developer profile it no longer reserves a Git branch
  or worktree, receives developer-environment tools or credentials, or carries
  developer workflow instructions.

## Session-scoped Odoo access

- OduPilot now checks **MCP Active** and the assigned MCP profile directly when
  each conversation starts. It no longer needs a permanent API key selected as
  the OduPilot default.
- Every eligible conversation still receives its own temporary MCP key, which
  is revoked when the conversation is closed or deleted.
