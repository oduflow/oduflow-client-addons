# 2026-08-22

## Start AI Developer from the current screen

- System administrators can now choose **AI Developer** in the developer bug
  menu, enter a request and open a new developer chat and Git worktree.
- The developer receives the current URL, action, menu, view, model, active
  record and selection, enriched with available XML IDs and record names.
- Administrators select the shared **Developers Profile** under
  **Settings → OduPilot → Settings**. The profile must contain the complete
  worktree, repository and developer-environment MCP configuration.

## Voice requests and automatic developer triage

- The **AI Developer** dialog now has **Dictate**: record a problem description,
  stop it and review the generated transcript before sending.
- AI first checks Prod Odoo and available documentation. It answers operational
  and configuration questions directly and asks whether more help is needed.
- When code must change, AI accepts the request for development. Odoo adds the
  globally configured **Responsible Developer** to the Discuss thread and sends
  that person a persistent notification.
- Administrators configure both **Developers Profile** and **Responsible
  Developer** under **Settings → OduPilot → Settings**.

## Chatter questions answered in a clean conversation

- Each **Ask AI** question from a chatter is now answered without the history
  of the previous questions, so AI no longer confuses the record you asked
  about with a record from an earlier question.
- Referring back to an earlier chatter question or answer is not possible any
  more; a conversation that remembers what was said is a chat in Discuss.
