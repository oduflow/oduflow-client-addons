# 2026-08-19

## A chatter question and its answer share one note

- A question asked with **Ask AI** stays a single internal note: the answer is
  added to the note that carries the question instead of arriving as a separate
  note below it. An open chatter shows the answer as soon as it is written,
  without a reload.
- The question and the answer used to sit in two notes ordered by time, so a
  record with several questions read as two interleaved lists.
- Chatter questions no longer open a conversation in Discuss. The service
  conversation is still used internally to run the request and to keep the
  reasoning and tool calls, but it is not shown in the sidebar; open it from
  **Settings → OduPilot → Sessions** when an answer has to be traced.
- AI never stops a chatter question to ask for permission. A profile rule set to
  **ask** is applied as **allow** for those questions, because the approval card
  would appear in a conversation nobody watches. Rules set to **deny**, the
  protection of `opencode.json` and the Bash denial of a **Files** profile are
  unchanged.
