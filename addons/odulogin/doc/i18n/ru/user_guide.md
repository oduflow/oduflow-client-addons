# Руководство пользователя OduLogin

OduLogin помогает администратору воспроизвести интерфейс внутреннего
пользователя, не запрашивая его пароль.

## Переключение с верхней панели

1. Войдите под учётной записью с правами администратора Настроек.
2. Выберите **Сменить пользователя** на верхней панели.
3. Выберите активного внутреннего пользователя и нажмите **Сменить пользователя**.
4. Odoo перезагрузит текущий URL от имени выбранного пользователя. Теперь
   действуют обычные правила доступа этого пользователя, поэтому на текущем
   экране может появиться ошибка доступа.

## Переключение из карточки пользователя

1. Откройте **Настройки > Пользователи и компании > Пользователи** и выберите пользователя.
2. Откройте меню **Действия** и выберите **Сменить пользователя**.
3. Подтвердите предварительно выбранного пользователя в диалоге.

## Возврат к учётной записи администратора

Выберите **Вернуться к администратору** на верхней панели. Odoo перезагрузит тот
же URL от имени исходного администратора.

В одной сессии браузера может быть активно только одно переключение. Перед
выбором другого пользователя вернитесь к учётной записи администратора. Нельзя
выбирать портальных и неактивных пользователей, текущего администратора и
технического суперпользователя.
