# Документация Oduscale

- Добавлены инструкции по выдаче VPN-доступа сотрудникам, подключению устройств,
  просмотру результатов синхронизации и отзыву ключей, устройств или всего доступа.
- Добавлена документация администратора по установке, правам, настройке Headscale,
  обращению с секретами и восстановлению после ошибок сервиса.
- Опубликованы польские и русские руководства и эта запись изменений для Книги.
- Инструкции модуля перенесены из обзора репозитория; в документации модуля добавлены
  ссылки на инструкцию развёртывания и техническую спецификацию.
- Исправлены подписи полей сервера: API URL, Login URL и Odoo URL.
- Общие инструкции развёртывания сервисов Oduflow перенесены в руководство администратора; детали демонстрационной установки сохранены в журнале развёртываний, добавлены правила ведения записей агентами.
