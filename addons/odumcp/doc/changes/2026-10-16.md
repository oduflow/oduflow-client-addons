# Odoo 20 support

- Version `20.0.1.4.1` installs on Odoo 20. Access rights now use the single `ir.access` model that Odoo 20 introduced in place of `ir.model.access` and `ir.rule`.
- `ir.access` replaces the two retired models in the read-only list of the profile-wide fallback, so a profile in write mode still cannot change access rights.
- Requests signed with an MCP key, including the managed Oduflow production key, are accepted on Odoo 20; previously every authenticated call was refused.
- Keys created with **Access: MCP only** are MCP-scoped on Odoo 20 instead of becoming general API keys.
