# 2026-08-21

## OduPilot no longer needs a permanent identity key

- Enabling **MCP Active** no longer creates a hidden permanent API key. OduPilot
  checks the active user, flag, and MCP profile directly and creates a separate
  temporary key for each conversation.
- The **OduPilot default** and **Managed by MCP access** columns and the related
  selection buttons were removed from Account Security. Personal MCP-only keys
  remain available for external clients and are independent from OduPilot.
- Closing or deleting an OduPilot conversation still revokes its temporary key.
  Disabling MCP makes existing session keys fail immediately without deleting
  a user's personal keys.
