# 2026-09-15

## OduMCP on Odoo 19

- Ported `odumcp` into `addons` as the policy, approval and audit dependency for OduPilot.
- Updated models, views, settings, access checks and group privileges for Odoo 19.
- MCP-only authentication now checks API-key expiration; OduPilot uses independent signed session tokens.
- Updated event polling and the accompanying MCP server, preserving private event tickets and per-user channels.
- Renamed the addon and all integration identifiers to `odumcp`: models, XML IDs, routes, settings, server package and `ODUMCP_*` variables. Install it as a new module; existing data is not migrated.
