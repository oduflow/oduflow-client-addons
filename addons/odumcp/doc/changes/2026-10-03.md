# Managed MCP key and profile renamed

- Version `19.0.1.4.1` names the managed administrator MCP key **MCP Admin** in the user's API Keys list.
- Keys named `Oduflow production (managed)` or `Oduflow production` by earlier versions keep working and are replaced by one `MCP Admin` key on the next synchronization. Personal keys and keys with another scope are untouched.
- Audit entries for current and earlier managed key names keep `source = oduflow`.
- Version `19.0.1.4.2` names the read-only MCP profile created for an administrator without a profile **MCP Administrators**.
- A profile created by earlier versions as `Oduflow administrators` is reused and renamed to **MCP Administrators** on the next synchronization; no second profile is created. A profile name changed by an administrator, the profile code and its settings are kept.
