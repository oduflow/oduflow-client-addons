# Managed MCP key renamed to MCP Admin

- Version `19.0.1.4.1` names the managed administrator MCP key **MCP Admin** in the user's API Keys list.
- Keys named `Oduflow production (managed)` or `Oduflow production` by earlier versions keep working and are replaced by one `MCP Admin` key on the next synchronization. Personal keys and keys with another scope are untouched.
- Audit entries for current and earlier managed key names keep `source = oduflow`.
