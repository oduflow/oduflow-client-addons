# 2026-08-19

## Allow Activities now covers the whole life of an activity

- The capability used to permit one thing: scheduling an activity. It now lets
  the connector manage the activities it owns end to end — read them, reassign
  them, move the due date, change the type, reword the summary and note, and
  close them.
- Ownership follows Odoo's own rule: an activity created by the connector user
  or assigned to them. A colleague's activity on the same record stays
  invisible and untouchable.
- Closing asks for a feedback note, which stays as a message in the record's
  chatter.

## Activities are closed, never deleted

- `record.delete` on `mail.activity` is refused while the capability is on, and
  there is no cancel action. An activity that is no longer needed is closed
  with a note saying so.
- Re-targeting an activity at another record is refused as well: its record
  fields are readable but not writable.
- Creating an activity as a bare record stays refused. Scheduling remains the
  only way in, because it checks write access on the record the activity is
  attached to.

## Auto-approval covers the activity group

- With **Auto Approve Low Risk** enabled, updating and closing an activity are
  auto-approved alongside scheduling one and posting a chatter message.
- An explicit Model Policy for `mail.activity` still overrides all of the
  above, including to allow deletion deliberately.
