# Odoo 16 compatibility

Use branch `16.0` for a fresh installation on Odoo 16. Install the module from `addons` together with its declared dependencies. This branch does not downgrade an existing Odoo database.

# Oduflow managed production access

- Added local installation and rotation of a supplied MCP key for the Odoo administrator, preserving personal keys and existing policies.
- New administrator profiles start read-only; write permissions remain an explicit Odoo configuration choice.
- Audit entries identify the managed integration credential with `source = oduflow`.
- The same module supports direct Oduflow integration and the standalone MCP server.
