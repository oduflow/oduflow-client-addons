# 2026-08-28

## Odrzucone połączenia złącza teraz powiedzieć, co naprawić

- Nazwa pola, która nie istnieje na modelu jest zgłaszana jako `unknown_field` zamiast `field_denied`. Typo lub pole pożyczone z innej wersji Odoo nie wygląda już jak problem z pozwoleniem.
- `field_denied`, `unknown_field` i `access_denied` teraz nazwy obraźliwe pola lub id rekordu w błędzie, więc odrzucone połączenie można naprawić w jednym kroku zamiast przez próby i błędy.
- Identyfikator rekordu, który nie istnieje, jest zgłaszany jako `record_not_found`, podczas gdy istniejący rekord poza zakresem profilu pozostaje `access_denied`. Zmieszane żądanie zawiera listę zarówno brakujących, jak i odrzuconych identyfikatorów w jednym błędzie.
- Opisy narzędzi łączących wskazują, że nazwy pól pochodzą z opisu modelu i że jedna zła nazwa lub id odrzuca całe połączenie.

## Opcjonalne częściowe odczyty zamiast odmowy połączenia

- Nowa funkcja profilu, **Częściowe odczyty pól**, odpowiada na odczyt za pomocą czytelnych kolumn i notatki `omitted_fields` zamiast odmówić. Jest domyślnie wyłączony, więc istniejące profile wciąż odmawiają takich połączeń.
- Przycinanie dotyczy tylko zwykłej listy pól. Zakazane pole w obszarze wyszukiwania lub w porządku sortowania nadal zawodzi, zapis nigdy nie jest przycinany, a czytanie, którego pola są zablokowane, nadal zawodzi, zamiast zwracać pusty sukces.
- Wiersz audytu częściowego odczytu zapisuje pominięte nazwy pól.

## Publikowanie obrazu bocznego

- `addons/odumcp/deploy/publish.sh` buduje pasek boczny i popycha go do Docker Hub zarówno w wersji `pyproject.toml` jak i `latest`, uruchamiając najpierw pakiet testowy i odmawiając nadpisania już opublikowanej wersji.
