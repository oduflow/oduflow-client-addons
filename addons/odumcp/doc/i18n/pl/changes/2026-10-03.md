# Zarządzany klucz MCP przemianowany na MCP Admin

- Wersja `19.0.1.4.1` nadaje zarządzanemu kluczowi MCP administratora nazwę **MCP Admin** na liście kluczy API użytkownika.
- Klucze nazwane przez wcześniejsze wersje `Oduflow production (managed)` lub `Oduflow production` nadal działają i przy następnej synchronizacji są zastępowane jednym kluczem `MCP Admin`. Klucze osobiste i klucze o innym zakresie pozostają bez zmian.
- Wpisy audytu dla bieżącej i wcześniejszych nazw klucza zarządzanego zachowują `source = oduflow`.
