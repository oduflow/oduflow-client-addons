# Zarządzany dostęp produkcyjny Oduflow

- Dodano lokalną instalację i rotację dostarczonego klucza MCP administratora Odoo z zachowaniem osobistych kluczy i istniejących polityk.
- Nowe profile administratora mają dostęp tylko do odczytu; uprawnienia zapisu konfiguruje się jawnie w Odoo.
- Wpisy audytu oznaczają zarządzany klucz integracji wartością `source = oduflow`.
- Ten sam moduł obsługuje bezpośrednią integrację Oduflow i osobny serwer MCP.
