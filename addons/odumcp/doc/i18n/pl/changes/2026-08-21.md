# 2026-08-21

## AI Czat nie potrzebuje już stałego klucza tożsamości

- Umożliwienie **MCP Aktywne** nie tworzy już ukrytego stałego klucza API. OduPilot sprawdza aktywny profil użytkownika, flagi i MCP bezpośrednio i tworzy osobny tymczasowy klucz do każdej rozmowy.
- Kolumny **AI Domyślna rozmowa** i **Zarządzanie dostępem MCP** oraz związane z nimi przyciski wyboru zostały usunięte z konta Security. Osobiste klucze MCP- pozostają dostępne dla klientów zewnętrznych i są niezależne od OduPilot.
- Zamknięcie lub usunięcie rozmowy Al Chat nadal odwołuje jej tymczasowy klucz. Wyłączenie MCP powoduje, że istniejące klucze sesji natychmiast zawodzą bez usuwania kluczy osobistych użytkownika.
