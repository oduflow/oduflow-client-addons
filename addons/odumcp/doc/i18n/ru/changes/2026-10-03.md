# Управляемый MCP-ключ переименован в MCP Admin

- Версия `19.0.1.4.1` называет управляемый MCP-ключ администратора **MCP Admin** в списке API-ключей пользователя.
- Ключи, названные прежними версиями `Oduflow production (managed)` или `Oduflow production`, продолжают работать и при следующей синхронизации заменяются одним ключом `MCP Admin`. Личные ключи и ключи с другой областью действия не затрагиваются.
- Записи аудита для текущего и прежних имён управляемого ключа сохраняют `source = oduflow`.
