# Поддержка Odoo 20

- Версия `20.0.1.4.1` устанавливается на Odoo 20. Права доступа теперь задаются единой моделью `ir.access`, которая в Odoo 20 заменила `ir.model.access` и `ir.rule`.
- `ir.access` заменяет две упразднённые модели в списке моделей, доступных резервному режиму профиля только на чтение, поэтому профиль в режиме записи по-прежнему не может менять права доступа.
- Запросы с MCP-ключом, включая управляемый ключ продакшена Oduflow, принимаются на Odoo 20; раньше любой вызов с аутентификацией отклонялся.
- Ключи, созданные с **Доступ: Только MCP**, на Odoo 20 получают область MCP, а не становятся обычными API-ключами.
