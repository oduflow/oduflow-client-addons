# 2026-08-21

## OduPilot больше не нужен постоянный ключ идентичности

- Включение **MCP Active** больше не создаёт скрытый постоянный API-ключ. AI
  Chat напрямую проверяет активность пользователя, галочки и MCP-профиля и
  создаёт отдельный временный ключ для каждой беседы.
- Колонки **OduPilot default** и **Managed by MCP access** вместе с кнопками
  выбора удалены из раздела безопасности учётной записи. Личные ключи только
  для MCP по-прежнему доступны внешним клиентам и не зависят от OduPilot.
- Закрытие или удаление беседы OduPilot по-прежнему отзывает её временный ключ.
  Отключение MCP сразу блокирует существующие сессионные ключи, не удаляя
  личные ключи пользователя.
