# Совместимость с Odoo 17

Для новой установки на Odoo 17 используйте ветку `17.0`. Установите модуль из `addons` вместе с объявленными зависимостями. Эта ветка не предназначена для понижения версии существующей базы Odoo.

# Управляемый доступ Oduflow к production

- Добавлена локальная установка и ротация заданного MCP-ключа администратора Odoo с сохранением личных ключей и существующих политик.
- Новые профили администратора доступны только для чтения; права записи настраиваются явно в Odoo.
- Записи аудита отмечают управляемый ключ интеграции значением `source = oduflow`.
- Один модуль поддерживает прямую интеграцию с Oduflow и отдельный MCP-сервер.
