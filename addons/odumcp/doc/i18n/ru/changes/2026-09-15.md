# 2026-09-15

## OduMCP на Odoo 19

- `odumcp` перенесён в `addons` как зависимость OduPilot для политик, подтверждений и аудита.
- Модели, представления, настройки, проверки доступа и привилегии групп обновлены для Odoo 19.
- Аутентификация только для MCP теперь проверяет срок действия API-ключа; OduPilot использует независимые подписанные токены сессий.
- Обновлены опрос событий и прилагаемый MCP-сервер с сохранением частных билетов событий и каналов пользователей.
- Модуль и все идентификаторы интеграции переименованы в `odumcp`: модели, XML ID, маршруты, настройки, серверный пакет и переменные `ODUMCP_*`. Устанавливайте его как новый модуль; существующие данные не переносятся.
