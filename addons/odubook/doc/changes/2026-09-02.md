# The Book opens on the change archive

- **Changes** now stands first in the **Book** menu, above **User Guide**.
- Opening the application from the app switcher lands on the change archive, so
  the newest entries are the first thing the Book shows.

## Login remains available during a Book upgrade

- Adding the personal **Book Language** preference no longer makes the login
  page unavailable while the server code is newer than the database schema.
- Existing personal Book language choices are preserved by the upgrade.
