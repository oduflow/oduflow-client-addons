# Module audit reports

- Added the administrator-only Audit menu, collecting `doc/module-audit.md`
  from installed modules with search, section links and PDF export.
- Added the `$audit-modules` skill for reviewing every module in `addons/`
  and writing evidence-based reports, including coverage and validation limits.
- Audit reports remain English source-only documents. Server access checks
  protect both reading and PDF export.
