# 2026-08-21 — Documentation Book

## `user_guide.md`

### Added

- **Manuals** is a new section beside **User Guide**: a shelf of documents added
  by hand, for files that do not live next to module code. Markdown and plain
  text are formatted like a guide, an HTML document runs inside the page, a PDF
  or an image is displayed as it is, and any other format is offered for
  download. **Download** always saves the original file.
- A document can carry several language versions. You open the one of your Odoo
  profile language, fall back to English or to the only version there is, and
  switch by hand with the **EN** / **PL** / **RU** buttons above the document.
- The shelf is not empty on the first open: the module ships **Sales Cube —
  sales management model**, the interactive artifact behind the Sales Cube, in
  English, Polish and Russian.
- Administrators see **Add a document** below the shelf, **Remove** beside
  **Download**, and a dashed language button for every missing translation —
  clicking it uploads that translation. Everyone else reads the shelf without
  changing it.
- Language buttons now sit above the text in every section of the Book, not on
  the Manuals shelf only. They offer the languages the documentation is actually
  written in, so a button never opens an empty page. The choice applies to what
  you are reading and is not remembered: your profile, your menus and your other
  windows stay in your own language.
- **Language** in the menu under your name changes the language of the whole
  interface: the window lists the languages installed in your database, marks
  the one you are working in, and the page reloads translated — menus, buttons,
  field labels, messages, reports and the Book with them. The setting is
  personal and identical to **Language** in **Preferences**; the page reloads,
  so save what you are editing first, and a language missing from the list has
  to be installed by an administrator.

### Changed

```diff
- the badge beside a month, a day or a module counts the unread entries
+ the filled badge on the left counts the unread entries and the pale badge on
+ the right counts every entry of the group
```

- The unread badge appears only while the group has unread entries, so the total
  is always visible in the same place.

## `admin_guide.md`

### Added

- The Manuals shelf: `odubook.manual` with one `odubook.manual.file` per
  language, read for internal users and full access for the Settings group, the
  extension → display table, the 25 MB file limit and the 4 MB render limit for
  text documents.
- Which version a reader gets: own language, then English, then the only one on
  the shelf. Uploading the same language twice replaces the file; removing the
  last version removes the document.
- The shipped Sales Cube document is created once with `noupdate="1"`, so
  editing or removing it in the UI survives the next upgrade.
- An uploaded HTML document is served with `Content-Security-Policy: sandbox`
  and framed without `allow-same-origin`, so its scripts cannot reach the
  reader's session.
- Where the language buttons come from: the mirrors present on disk, per
  document and without any configuration record. A language appears with the
  first `doc/i18n/<lang>/` mirror of that document and disappears with the last;
  English is always offered, and a language requested outside that list is
  ignored by the server.
- The user-menu **Language** dialog writes `lang` on the reader's own
  `res.users` record and reloads the page. No group guards it and nothing has to
  be configured: `lang` is a self-writeable user field. It lists the active
  `res.lang` records, so a language shows up only once installed — while the
  Book's own buttons work for a language absent from the database.

## `tech_spec.md`

### Added

- Models `odubook.manual` and `odubook.manual.file` (one file per language,
  `unique(manual_id, lang)`) with `get_manuals(lang)`, `read_manual(id, lang)`,
  `upload_manual(..., lang, manual_id)` and `delete_manual(id, lang)`, the
  extension-driven `kind` and `format`, the `MAX_MANUAL_BYTES` /
  `MAX_RENDERED_BYTES` limits and `FALLBACK_LANG`.
- Endpoints `POST /odubook/manuals`, `/odubook/manuals/read`,
  `/odubook/manuals/upload`, `/odubook/manuals/delete` — all language-aware —
  and `GET /odubook/manual/<file_id>/<filename>` with its `nosniff` and sandbox
  headers.
- `ManualsApp`: lazy per-document and per-language text, framed HTML and PDF,
  language buttons that re-request the index, the upload block behind
  `can_edit`, and removal guarded by a confirmation dialog.
- The two sidebar badges of a change group: unread on the left, total on the
  right.
- `get_book(lang)`, `get_admin_book(lang)`, `get_changes(lang)` and
  `read_changes(entries, mark_read, lang)` with their `languages` / `lang`
  payload, plus `_doc_languages`, `_has_mirror`, `_language_names`,
  `_selected_lang`, `get_ui_languages` and `SOURCE_LANG`.
- Endpoint `POST /odubook/languages`, and the optional `lang` of
  `/odubook/book`, `/odubook/admin`, `/odubook/changes` and
  `/odubook/change`.
- `LanguageDialog` in the `user_menuitems` registry, and the language buttons of
  `BookApp` and `ChangesApp`.
