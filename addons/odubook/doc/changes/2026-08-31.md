# Several chapters in one PDF

- A checkbox now sits beside every heading of a guide, next to the PDF and link
  buttons.
- Ticked headings form a set that survives moving between guides, so chapters of
  different modules can leave the Book as a single PDF.
- While the set is not empty, **Export selected sections** and **Clear the
  selection** stand above the document.
- The set is kept by the browser, so reloading the page no longer empties it.
- The change archive got the same checkbox, at the head of every entry:
  **Export selected entries** takes the ticked ones out as one PDF, and its set
  is kept apart from the set of the guides.
- Every entry of the change archive now says when it was **published** — the
  moment it reached this server — and the archive is ordered by that moment,
  the freshest on top. The day an entry carries is still the day its author
  filed it, so a change written on Friday and published on Monday now stands
  among Monday's news instead of hiding under Friday.
