# Совместимость с Odoo 18

Добавлен раздел аудита для администраторов с поиском отчётов и экспортом PDF.

Для новой установки на Odoo 18 используйте ветку `18.0`. Установите модуль из `addons` вместе с объявленными зависимостями. Эта ветка не предназначена для понижения версии существующей базы Odoo.
