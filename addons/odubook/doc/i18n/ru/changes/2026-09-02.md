# Книга открывается на летописи изменений

- **Изменения** теперь стоят в меню **Книга** первыми, выше **Руководства
  пользователя**.
- Открытие приложения из переключателя приложений сразу попадает на летопись
  изменений, поэтому свежие записи — первое, что показывает Книга.

## Вход остаётся доступен во время обновления Книги

- Добавление личной настройки **Язык Книги** больше не делает страницу входа
  недоступной, когда код сервера новее схемы базы данных.
- Обновление сохраняет уже выбранный личный язык Книги.
